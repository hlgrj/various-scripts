# various-scripts
A collection of small utility scripts for everyday tasks.

## Scripts

| Script | Description | References |
|--------|-------------|------------|
| [bash/heic_to_jpeg.sh](bash/heic_to_jpeg.sh) | Batch-converts HEIC images to JPEG using `sips` (macOS) and strips all metadata through usage of `exiftool`. Usage: `./heic_to_jpeg.sh <input_folder> <output_folder>` | [exiftool.org](https://exiftool.org) |
